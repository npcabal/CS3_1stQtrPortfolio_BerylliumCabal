### 1. List and describe at least 5 topics that we discussed in class that you know very well. Each description should be at least 1 paragraph with two to five sentences.
1. **Arithmetic Operators** - They are used when you want to perform calculations. They work on numbers and also combine strings using the `+` operator. These include `+` (addition), `-` (subtraction), `*` (multiplication), `/` (division), `+` (addition), and `%` (modulo for finding the remainder).  
2. **Variable Declarations** - Variables are used for storing data values. You can declare variables using keywords like `var, let,` or `const`. Use `let` for variables that can be changed, and `const` for variables that can't be changed.
3. **Comparison Operators** - They are used to compare two values and return a boolean result (`true` or `false`). Common oparators include `==` (equality), `!=` (inequality), `===` (strict equality), `!===` (strict inequality), `>` (greater than),  `<` (less than), `>=` (grater than or equal to), and `<=` (less than or equal to), `==` (equality). The operator `==` chacks the value equality, while `===` checks the values and types.
4. **Control Statements** - They are used to manage the flow of an execution. THey include conditional statements like `if, if-else,` and `switch` for making decisions based on the conditins. They also include loop statements like `for, while,` and `do-while` for repetitive execuions. Statements like `continue` and `break` control the behavior of the loops.
5. **Fuctions** - They are reusable blocks of code for performing a specific task. It is defined using the keyword `function`, followed by a name, and parentheses (that can hold parameters), and then a code block. They can be called to execute their code. Functions can return a value or perform an action.
